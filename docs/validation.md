# Проверка демо

Проверено 14 октября 2026 года на Python 3.12 в WSL; интерфейс — в установленном Windows Edge через Playwright.

## Автоматические проверки

`python3 -m unittest discover -s tests -v`: **31 тест прошёл**. Проверяются периоды и границы дат, текущий портфель со старыми сделками, завершённые и просроченные задачи, атрибуция звонков менеджерам, пагинация и повторы amoCRM, HTTP 204/429/5xx, неполная выгрузка, проверка цитат модели, формат ASR и локальный HTTP API.

`python3 -m compileall -q auditor examples` и `node --check dist/app.js` прошли. Самостоятельный пример amoCRM занимает ровно 50 строк.

## Интерфейс

В браузере проверены переключение периода, фильтр менеджера, совпадение сумм графика и отчёта, поиск и фильтр проблемных сделок, карточки и расшифровки, возврат фокуса и управление с клавиатуры, JSON/Markdown выгрузка, формирование отчёта, мобильная вёрстка и меню, статический режим и видимые ошибки API. Импортируемый текст проверен на безопасное отображение HTML-подобных строк.

Скриншоты в `docs/screenshots/` получены из работающего интерфейса, а не из макета.
